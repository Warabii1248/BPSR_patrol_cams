# GAS連携 Chrome拡張 導入ガイド

GASの討伐タイマーページを開いておくだけで、湧き間近のチャンネルを
BPSR Patrol Cams の巡回リストへ自動送信する Chrome 拡張です。

この `gas_extension` フォルダがそのまま拡張機能本体です。以下の手順で Chrome / Edge に追加します。

---

## 1. 拡張機能を Chrome に追加する

1. Chrome を開き、アドレスバーに `chrome://extensions` と入力して Enter
   - Microsoft Edge の場合は `edge://extensions`
2. 画面右上の **「デベロッパーモード」** スイッチを **ON** にする
3. 左上に出てくる **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリック
4. この **`gas_extension` フォルダ**（`manifest.json` が入っているフォルダ）を選んで「フォルダーの選択」
5. 一覧に **「BPSR patrol cams GAS Sync」** が追加されれば完了

> 拡張機能を更新したとき（ファイル差し替え時）は、拡張一覧の更新（↻）ボタンを押すか、
> 一度削除して再度読み込み直してください。

---

## 2. 使い方

1. **BPSR Patrol Cams 本体を起動しておく**（拡張は `http://localhost:8080` に送信するため、本体が起動していないと送れません）
2. 本体の設定で GAS 連携を有効にする
   - GUI の「設定」または `config.json` で `gas_enable` を `true`（デフォルト ON）
   - `gas_target_enemy` に拾いたいモンスター名を指定（部分一致、例: `金ウリボ` / `金ナッポ`）
3. ブラウザで **GASの討伐タイマーページを開く**
   - ページを開くと拡張が自動で動き出します（操作不要）
   - 送信が成功すると、ページ右下に緑色のバッジ（例: `✓ 3件 送信済`）が数秒表示されます

これだけで、湧き間近のチャンネルが自動的に巡回リストへ反映されます。

---

## 3. 動作の仕組み（参考）

- タイマーページを開いてから **約10分ごと** に自動チェック
- 残り時間が **しきい値（20時間経過）以上** のチャンネルだけを抽出
- 抽出した `{チャンネル番号, モンスター名}` を本体の `POST /api/patrol/channels/gas` へ送信
- 本体側で `gas_target_enemy` に一致するものだけが巡回リストにマージされる

---

## 4. うまくいかないとき

| 症状 | 確認すること |
|---|---|
| 右下のバッジが出ない | タイマーページを開いているか／拡張が有効（ON）か |
| `✗ 接続失敗（Go起動確認）` と出る | BPSR Patrol Cams 本体が起動しているか／`gui_port` が 8080 か |
| 送信しても巡回に反映されない | `gas_enable=true` か／`gas_target_enemy` がページ上のモンスター名と部分一致するか |
| `0ch（送信なし）` と出る | しきい値（残り時間）以上のチャンネルが現時点で無いだけ（正常） |

> 拡張の詳細ログはブラウザの開発者ツール（F12）→ Console に `[GAS Sync]` 付きで出ます。
